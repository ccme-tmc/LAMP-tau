# LAMP-tau

This is a package based on PySCF to analyse the magnetic property from ab-inito calculation, recommand to use with LAMP-emb(https://github.com/ZGuan97/LAMP_emb)

"mag_anal" is the core component of this package. It can be used to analyze the ab initio calculation results of single-ion magnets obtained with lamb-emb, thereby extracting the magnetic properties of the system. Alternatively, it can employ the spin-phonon coupling coefficients generated by "SPC_Tool" to calculate relaxation times and analyze relaxation processes.

"SPC_Tool" is a toolkit designed for computing spin-phonon coupling (SPC) parameters. Currently, it supports only phonon calculations using VASP and the computation of spin-phonon coupling coefficients using Molcas/OpenMolcas/PySCF platform. A detailed manual is provided within the software package. Users should note that some of the .sh scripts need to be adapted according to their specific high-performance computing platform or server.
